DICTIONARY DATA CREDITS AND LICENSE

The dictionary.txt file is derived from the default English word list in:
https://github.com/neopass/wordlist

The source project describes its default list as an approximately 86,000-word English list generated from SCOWL and related additions. This project filters the source to unique lowercase alphabetic entries of 3 or more letters.
