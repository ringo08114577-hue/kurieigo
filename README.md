# クリエイゴ (Creigeo)

30秒で、配られた8種類のアルファベットから英単語を作るブラウザゲームです。

## ページ構成
- `index.html`: ホーム画面。遊び方と得点表を表示します。
- `game.html`: ゲーム専用画面。ホームとは別ページです。
- `style.css`: ホーム・ゲーム共通のデザイン。
- `home.js`: ホーム画面に最高得点を表示します。
- `game.js`: 文字配布、タップ入力、タイマー、判定、得点、最高記録の保存。
- `dictionary.txt`: 英単語辞書（約86,634語）。
- `DICTIONARY-LICENSE.txt`: 辞書データの出典とライセンス表記。

## ゲームルール
- 30秒のラウンド制。
- 母音 A/E/I/O/U から重複なしで2文字、子音から重複なしで6文字を選び、合計8文字をシャッフルして配ります。
- 使えるのは配られた8種類の文字だけです。単語内では同じ文字を何回使っても構いません。
- ゲーム画面下部の8つの文字ボタンをタップすると、中央の単語欄に文字が追加されます。
- 3文字=1点、4文字=3点、5文字=5点、6文字=7点、7文字=9点、8文字=11点。9文字以上は1文字増えるごとに2点追加。
- 同じ単語は1ラウンドで1回しか得点になりません。
- 辞書にある3文字以上の単語だけ有効です。
- 「1文字戻す」「全部消す」で入力を修正し、「この単語で決定」で判定します。PCでは配布文字のキー入力、Enter、Backspace、Escapeにも対応します。

辞書は `neopass/wordlist` の `default.txt` をもとに、重複を除き、3文字以上の英小文字だけを抽出しています。出典とライセンスは `DICTIONARY-LICENSE.txt` を参照してください。
