# クリエイゴ (Creigeo)

30秒で、配られた8種類のアルファベットから英単語をできるだけ多く作るブラウザゲームです。

## ファイル
- `index.html`: ゲーム画面
- `style.css`: デザイン
- `game.js`: タイマー、文字配布、判定、得点
- `dictionary.txt`: 英単語辞書データ

## ルール
- 母音5文字から重複なしで2文字、子音から重複なしで6文字を選び、全体をシャッフルします。
- 単語に使えるのは配布された8種類の文字だけです。単語内では同じ文字を何度使っても構いません。
- 3文字=1点、4文字=3点、5文字=5点、6文字=7点、7文字=9点、以降は1文字増えるごとに2点増えます。
- 同じ単語は1ラウンドで1回しか得点になりません。
- 辞書にある3文字以上の単語だけ有効です。

## 公開
GitHub Pagesでリポジトリのルートを公開すると動作します。辞書ファイルはゲームと同じ場所に置きます。

## 辞書について
現在の `dictionary.txt` は動作確認用の初期辞書です。大規模な辞書を完成させるには、利用・再配布ライセンスを確認したうえで公開英単語リストを追加してください。現在の収録語数を「巨大な辞書」とはみなしていません。
